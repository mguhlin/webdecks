Web Deck v5

A tiny system for self-contained HTML slide decks. No build step, no framework, no dependency beyond Google Fonts.

What it is

A single HTML file that presents fullscreen, carries teleprompter speaker notes, drives a two-monitor presenter view (with A−/A+ notes resizing), exports to PDF, and reflows to read on a phone.

  • Fixed 1280×720 canvas that scales to any screen.
  • Cover, divider, and content slide types with ready-made blocks (bullets, cards, steps, callouts, compare, scenario, and more).
  • Editorial blue-and-silver reference skin you can re-skin per project with a few CSS variables.
  • WCAG 2.1 AA layer: reflow, visible focus, live region, reduced motion.

Use it with a chatbot

  1. Download the Standalone instructions above and upload (or paste) it into ChatGPT, Claude, Gemini, or similar.
  2. Ask for a deck. For example:
Using the Web Deck v5 system in the document I just gave you, build a single self-contained HTML file deck on [topic] for [audience], about [N] slides. Paste Appendix A into one <style> and Appendix B verbatim into one <script>. Write real teleprompter speaker notes in every slide. Output the complete file.

The chatbot returns one portable .html you save and open — nothing else required.

Use it in a project

Copy assets/deck-framework.css and assets/deck-framework.js into your project's assets/, copy decks/template-deck.html, re-skin the palette and fonts in the deck's own <style>, and replace the slides. Full details in the spec.
